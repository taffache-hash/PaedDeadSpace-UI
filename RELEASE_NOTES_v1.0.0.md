# PaedDeadSpace-UI v1.0.0

First public release of the Streamlit interface. The UI imports PaedDeadSpace-Core v1.0.0, keeps apparatus dead space separate from patient dead space, exposes source/provenance information, and reproduces the Pearsall golden benchmark.

Release-only changes include version display, About/Citation metadata, documentation, and packaging. Scientific equations remain exclusively in the Core.
